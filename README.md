# MotoFare Kigali

> Know the fair price before you ride.

A web app helping riders in Kigali get fair moto-taxi fare estimates,
built for ALU students and anyone navigating Kigali's moto-taxi routes.

## Features

- Custom fare estimator using real road distance
- Fixed routes for common ALU Campus trips
- Student discount support (20% off)

## Setup

Open `index.html` in any modern browser. No build step required.

## APIs

- Nominatim (OpenStreetMap) — free geocoding, no key needed
- OSRM (Open Source Routing Machine) — free road routing, no key needed
